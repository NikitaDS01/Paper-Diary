# Бумажный дневник A5 — HTML-макеты страниц

Это **не веб-приложение**. Каждая страница — макет листа A5 (148×210 мм) для
перерисовки от руки в дневник на кольцах. Открой `index.html` в браузере —
там оглавление с миниатюрами; каждая страница открывается отдельно.

## Структура

    index.html            оглавление + правила использования
    assets/pages.css      общие стили листа A5 (поле под кольца, таблицы, легенды)
    assets/grid.js        генератор дней 1–31, клеток, линейки дней, осей и мини-календарей
    year/goals.html       Цели на год — 5 карточек: цель · результат · шаги
    year/events.html      Важные события — по 2 строки на месяц
    year/books.html       Книги — 21 запись: автор, даты начала/конца, ★1–5
    year/covers.html      Обложки книг — сетка 4×4: обложку зарисуй/вклей, ★1–5
    year/movies.html      Фильмы — 21 запись: дата просмотра, ★1–5
    year/serials.html     Сериалы — 21 запись по сезонам, дата финиша, ★1–5
    year/manga.html       Манга и манхва — 21 запись: дата финиша, ★1–5
    month/overview.html   Календарь + задачи + события месяца
    month/calendar.html   Карта дат с цветовой маркировкой типов событий
    month/habits.html     Ежедневные отметки выполнения привычек
    month/graphs.html     Численные показатели по дням: настроение/погода, сон, энергия
    month/stats.html      Мини-календари — до 6 показателей «было / не было»
    month/screentime.html Экранное время: <2 ч / 2–5 ч / 5+ ч — три цвета
    month/reading.html    Страницы по дням + свои диапазоны для закраски
    month/budget.html     Бюджет: доходы, расходы, план/факт, итог
    custom/builder.html   Конструктор — свой лист A5 из готовых частей

## Соглашения макетов

- Пунктир «……» — место для твоей надписи.
- Серые строки курсивом — примеры, на бумаге не рисуются.
- Левое поле с кружочками — отступ под кольца.
- Цвет = результат: легенды и диапазоны вписываешь сам.
- Есть кнопка «Печать A5» (@page A5, поля 0), но задумано рисовать вручную.
- Свой лист собери сам в `custom/builder.html`: части-блоки ложатся сверху вниз, индикатор
  показывает, сколько рабочей высоты листа они уже заняли, и предупреждает, если не влезают.
- Скачанный оттуда `page.html` клади в `custom/`: только там он подхватывает общие
  `assets/pages.css` и `assets/grid.js` и печатается как обычная страница.
