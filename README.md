# Бумажный дневник A5 — HTML-макеты страниц

Это **не веб-приложение**. Каждая страница — макет листа A5 (148×210 мм) для
перерисовки от руки в дневник на кольцах. Открой `index.html` в браузере —
там оглавление с миниатюрами; каждая страница открывается отдельно.

## Структура

    index.html            оглавление + правила использования
    assets/pages.css      общие стили листа A5 (поле под кольца, таблицы, легенды)
    assets/grid.js        генератор дней 1–31 и клеток трекеров
    year/goals.html       Цели на год — 5 карточек: цель · результат · шаги
    year/events.html      Важные события — по 2 строки на месяц
    year/books.html       Книги — автор, даты начала/финиша, ★1–5
    year/media.html       Фильмы и сериалы — два списка, ★1–5
    year/manga.html       Манга и манхва — дата финиша, ★1–5
    month/overview.html   Календарь + задачи + события месяца
    month/habits.html     Трекер привычек (вода 2 л, дневник, чтение + пустые строки)
    month/screentime.html Экранное время: <2 ч / 2–5 ч / 5+ ч — три цвета
    month/reading.html    Страницы по дням + свои диапазоны для закраски
    month/budget.html     Бюджет: доходы, расходы, план/факт, итог

## Соглашения макетов

- Пунктир «……» — место для твоей надписи.
- Серые строки курсивом — примеры, на бумаге не рисуются.
- Левое поле с кружочками — отступ под кольца.
- Цвет = результат: легенды и диапазоны вписываешь сам.
- Есть кнопка «Печать A5» (@page A5, поля 0), но задумано рисовать вручную.
